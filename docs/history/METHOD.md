# 方法与实验约束

研究问题：模型能否接管原由多次调用、分支和恢复程序执行的决策，并在能力保留时降低实际运行成本？不能仅凭删代码、技能生命周期或蒸馏本身主张创新。

## 固定设计

- `H_core` 保留原环境、工具、动作解析、公开历史与环境权限边界。
- 可演化部分限制为 planner/replanner、draft-review、failure recovery；候选不能执行环境动作。
- 每轮固定当前模型，采集 search 训练子集轨迹；产生两个模块候选，通过接口、search、dev 评价选择。一次新增一个主要模块。
- 学生实际使用 `H-` 访问状态。教师使用阶段初冻结模型和 `H+`，只读取该状态学生实际可见的公开输入。不能用未来观察、参考答案、隐藏状态或已被学生截断的历史。
- 若 H− 非空，保留模块用当前 actor 生成临时指导。共享环境历史单独保存为 `obs_text_base`，学生 prompt 必须完整保留该前缀；教师从同一原始历史重新执行冻结 H+，不会复用学生保留模块产生的内部指导。辅助调用输出不进入学生 response 训练张量。
- 教师对学生已生成动作 token 打分；原生 OPID 任务奖励继续生效，模块指导进入 step teacher advantage。不另写 RL 优化器。
- 定向监督覆盖模块触发与持续影响窗口。持续窗口只决定是否重算当步指导，不携带教师独占记忆。all-step 为消融。
- 当前 review 使用冻结教师生成的未执行 draft，然后 review，再对学生动作打分；不把实际学生动作当作模块输入，也不执行教师 draft。
- 每个周期教师、模块与阶段 manifest 固定，参数更新后生成新 checkpoint，不能覆盖教师文件。

## 撤除判据

| | 完整 H+ | 精简 H- |
|---|---|---|
| 训练前 | A | B |
| 训练后 | C | D |

要求 A−B 和 D−B 的配对置信区间下界 > 0；D−A 和 D−C 的下界 ≥ −0.02；至少 30 个独立任务。任务 ID 是 bootstrap cluster，重复 seed 不伪装成独立样本。

还要求 D 相对 A、C 的总 token 至少下降 5%，辅助调用下降，总模型调用、工具调用与延迟不增加，均按配对区间判断。保守门槛可调整，但应在正式实验前固定，不能根据测试成绩追调。

未通过则保留。候选没有表现出收益则跳过该轮，预算记为未使用。原本无效或冗余的候选不会计作内化成功。归档保留模块源码及 hash。

每轮使用预先划定的独立 `retirement_k` 任务队列；不把该队列结果和轨迹传入 proposer。最终 test 不进入外层调度。性能置信区间是逐对区间，不代表整篇论文的多重比较校正；正式统计方案仍需固定主终点、独立复验和跨训练 seed 汇总。

## 基准与对照

主实验顺序 ALFWorld、WebShop、Search-QA，AppWorld 后续扩展。ALFWorld 使用文本环境；训练内部拆分 train/search/dev/retirement，官方 seen/unseen 留作最终评价。WebShop 使用完整商品配置，固定 train≥1500、dev=500..1499、test=0..499，再拆分内部选择队列。Search-QA 固定数据、语料、索引和检索 top-k；保留检索工具。AppWorld 模块不得硬编码任务 API 流程。

必须对照：冻结模型＋增强 Harness、同预算 RL、原 OPID、固定 Harness 蒸馏/OPHSD、SLIM、同策略文本技能、无退役、all-step、单轮蒸馏。WHALE/PATS 记录为相关对照和新颖性边界，当前没有复现。

目标图表：每轮 A/B/C/D 能力保留；成本—性能；连续周期与旧模块能力回归检查。训练步数只是调度预算，论文需额外比较样本数、总生成与打分 token、GPU 时间和总搜索/验证成本。当前默认 300 步仅是初始可配置工程值，不是确定的论文预算。
